# Contributing to Interest Calculator

First off, thank you for taking the time to contribute! 🎉

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

---

## How Can I Contribute?

### 🐛 Reporting Bugs
If you find a bug or unexpected behavior, please check if there is already an open issue for it. If not, feel free to open a new issue. Please include:
- A clear description of the bug
- Steps to reproduce the issue
- Expected vs. actual behavior
- Screenshots (if applicable)

### 💡 Suggesting Enhancements
Have an idea to make this Interest Calculator even better? We'd love to hear it! Open an issue with:
- A clear explanation of the proposed feature
- The problem it solves or the benefit it brings
- Any visual design mockups or implementation ideas

### ✍️ Documentation Improvements
Improving documentation helps everyone. You can submit pull requests for:
- Correcting typos or grammar mistakes
- Clarifying setup or calculation instructions
- Adding examples or details to the README

### 💻 Code Contributions
If you want to write code (fixes or features):
1. **Fork the Repository** and create your branch from `main`.
2. **Develop**: Keep your code clean, self-documented, and follow standard web accessibility rules.
3. **Commit & Push**: Commit your changes with descriptive commit messages.
4. **Open a Pull Request**: Provide a detailed description of what your changes accomplish.

---

Please note that this project is released with a [Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project, you agree to abide by its terms.
